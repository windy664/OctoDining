## 🚀 快速开始

### 运行（OctoScript 小程序）

```bash
# 1. 克隆项目
git clone https://github.com/windy664/OctoDining.git
cd OctoDining

# 2. 运行小程序
cd /home/windy/Project/octosense-ws/OctoScript-App-Design-Flow
tools/octo run /path/to/OctoDining/bundle --port 8160 --detach

# 3. 打开浏览器访问
# http://localhost:8160
```

### 使用

1. **选择资产等级**（A1-A6）
2. **输入预算**（如：20元）
3. **输入需求**（如：吃饱一点，别太辣）
4. **点击 AI 规划**
5. **查看推荐结果**
6. **加入采购清单**

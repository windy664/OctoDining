# 🍽️ 校园美食规划助手

**Agentic App 黑客松 2026 参赛作品**

> 基于广州软件学院真实食堂数据，AI 帮你规划一周美食，支持 5 个预算档次

---

## 📊 核心数据

### 广州软件学院食堂数据

| 数据文件 | 记录数 | 说明 |
|----------|--------|------|
| `all_menus.json` | 106,419 行 | 完整菜单分类数据 |
| `menu.csv` | 2,085 条 | 商品明细（食堂二楼等） |
| `products_clean.json` | 300+ 条 | 清洗后商品数据 |
| `menus/` | 30+ 文件 | 各店铺菜单 JSON |

### 商品字段

```
店铺ID, 店铺名称, 地址, 电话, 行业分类, 营业时间, 
是否营业中, Logo图片, 外卖起送费, 配送费, 距离(km),
商品ID, 商品名称, 分类, 价格, 原价, 库存, 是否缺货,
商品图片, 条码, 描述, 是否新品, 创建时间
```

## 💰 5 个预算档次餐表

| 档次 | 文件 | 定位 | 日均预算 |
|------|------|------|---------|
| **A1 特困级** | `meal_plan_A1.csv` | 极限省钱 | ~15 元 |
| **A2 困难级** | `meal_plan_A2.csv` | 经济实惠 | ~20 元 |
| **A3 普通级** | `meal_plan_A3.csv` | 正常消费 | ~25 元 |
| **A4 小康级** | `meal_plan_A4.csv` | 较好伙食 | ~35 元 |
| **A5 富裕级** | `meal_plan_A5.csv` | 丰富多样 | ~50 元 |

### 餐表格式

```csv
日期,档次,早餐,早餐价格,午餐,午餐价格,晚餐,晚餐价格,下午茶,下午茶价格,夜宵,夜宵价格,水果,水果价格,当日合计
周一,A1 特困级,葱油饼,5,加芽菜肉沫,4,+小鲜肉（单点不做）,4,,0,,0,,0,13
周二,A1 特困级,香辣劲脆鸡排（小吃）,5,+花蛤肉（单点不做）,5,+花蛤肉（单点不做）,5,,0,,0,,0,15
...
```

### 餐次覆盖

| 餐次 | 说明 |
|------|------|
| 🌅 早餐 | 7:00-9:00 |
| ☀️ 午餐 | 11:00-13:00 |
| 🌙 晚餐 | 17:00-19:00 |
| 🍰 下午茶 | 14:00-16:00（可选） |
| 🌜 夜宵 | 21:00-23:00（可选） |
| 🍎 水果 | 全天（可选） |

## 🎯 功能特点

| 功能 | 说明 |
|------|------|
| 💰 预算分级 | 5 个档次，从特困到富裕 |
| 🍳 真实数据 | 广州软件学院食堂 2000+ 商品 |
| 📅 一周规划 | 周一到周日完整餐表 |

| 🛒 采购清单 | 自动生成采购清单 |

## 🎯 场景说明

### 痛点

| 问题 | 现状 |
|------|------|
| 不知道吃什么 | 每天纠结 |
| 预算难控制 | 花钱没计划 |
| 营养不均衡 | 随意搭配 |
| 采购靠手写 | 容易遗漏 |

### 解决方案

```
选择预算档次 (A1-A5)
        ↓
AI 分析食堂菜单
        ↓
生成一周餐表
        ↓
计算采购清单
        ↓
执行采购
```

---

## 🤖 Agent 自动化

| 步骤 | Agent 任务 | 输入 | 输出 |
|------|-----------|------|------|
| 1 | 分析预算 | 档次选择 | 预算范围 |
| 2 | 匹配菜单 | 预算+偏好 | 可选菜品 |
| 3 | 生成餐表 | 可选菜品 | 一周餐表 |
| 4 | 计算采购 | 餐表 | 采购清单 |

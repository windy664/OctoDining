# OctoDining 数据与隐私说明

更新：2026-10-05。本说明对应应用版本 1.6.0；实际运行由所用 OctoSense Shell 和模型服务商共同决定。

OctoDining 使用随应用打包的 1,497 条菜单快照筛选候选。首次引导输入的每月可支配生活费、非餐饮固定开销和缓冲金用于本机估算饭钱，并写入宿主分配的本地 `profile.json`。中文 / English 的选择写入本地 `language.json`。你输入的日期、餐次、预算、到店时间和需求用于本机筛选；确认后的计划写入同一应用存储中的 `plans-a.json` / `plans-b.json`。应用没有账号注册、订单、支付或定位接口。

只有点击“让 OctoSense Agent 比较”时，应用才通过宿主的 `octos.turn.start` 服务发送本次需求、**每日及单餐预算**、餐次、最多三个候选和当天已有计划摘要；月生活费、固定开销和缓冲金原值不在请求中。模型服务商由 OctoSense Shell 的使用者配置；若配置云端模型，这些内容会由宿主传给相应服务商，适用该服务商的处理规则。应用本身不读取模型密钥，也不直接向外部网络发起请求。Agent 只给建议；保存计划仍需用户确认。

取消计划会更新本地计划记录。当前应用没有提供彻底清除宿主存储、导出数据或跨设备同步的功能；如需删除应用数据，应通过所用宿主的应用数据管理方式处理。菜单快照的采集日期、来源凭据和再分发许可仍在核实；不要把快照当作实时或安全饮食信息。

项目问题与支持：<https://github.com/windy664/OctoDining/issues>。

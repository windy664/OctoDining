# Agent 任务演示

## 概述

本文档说明 Agent 在「校园美食规划助手」中如何自动完成任务。

---

## Agent 工作流程

```
┌─────────────────────────────────────────────────────┐
│                    用户操作                          │
│  选择偏好 → 点击开始                                 │
└─────────────────┬───────────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────────┐
│              Agent 任务执行                          │
│  ┌─────────────────────────────────────────────┐   │
│  │ 1. 分析偏好                                  │   │
│  │    输入: ["healthy", "quick"]                │   │
│  │    输出: 偏好画像 = {健康, 快手, 营养均衡}    │   │
│  └─────────────────────────────────────────────┘   │
│                      ↓                              │
│  ┌─────────────────────────────────────────────┐   │
│  │ 2. 匹配营养                                  │   │
│  │    输入: 偏好画像                            │   │
│  │    输出: 营养需求 = {1850kcal, 85g蛋白}      │   │
│  └─────────────────────────────────────────────┘   │
│                      ↓                              │
│  ┌─────────────────────────────────────────────┐   │
│  │ 3. 生成菜谱                                  │   │
│  │    输入: 营养需求 + 菜谱库                    │   │
│  │    输出: 早/午/晚餐菜谱                      │   │
│  └─────────────────────────────────────────────┘   │
│                      ↓                              │
│  ┌─────────────────────────────────────────────┐   │
│  │ 4. 计算采购                                  │   │
│  │    输入: 菜谱 + 用量模板                     │   │
│  │    输出: 采购清单                            │   │
│  └─────────────────────────────────────────────┘   │
└─────────────────┬───────────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────────┐
│                    结果展示                          │
│  营养统计 + 菜谱 + 采购清单                          │
└─────────────────────────────────────────────────────┘
```

---

## 任务 1: 分析偏好

### 输入

```json
{
  "selected_tags": ["healthy", "quick"]
}
```

### Agent 操作

```
1. 解析用户选择的标签
2. 映射到营养需求
3. 生成偏好画像
```

### 输出

```json
{
  "profile": {
    "taste": ["light", "healthy"],
    "nutrition": ["balanced", "high_protein"],
    "cooking_time": "quick"
  }
}
```

---

## 任务 2: 匹配营养

### 输入

```json
{
  "profile": {"taste": ["light", "healthy"]}
}
```

### Agent 操作

```
1. 查询营养数据库
2. 计算每日需求
3. 分配三餐比例
```

### 输出

```json
{
  "daily_needs": {
    "calories": 1850,
    "protein": 85,
    "meals": 3
  }
}
```

---

## 任务 3: 生成菜谱

### 输入

```json
{
  "daily_needs": {"calories": 1850, "protein": 85},
  "preferences": ["healthy", "quick"]
}
```

### Agent 操作

```
1. 筛选符合条件的菜谱
2. 平衡营养搭配
3. 确保多样性
```

### 输出

```json
{
  "breakfast": {
    "name": "牛油果吐司配水波蛋",
    "calories": 380,
    "protein": 18,
    "time": "15分钟"
  },
  "lunch": {
    "name": "藜麦鸡胸肉沙拉",
    "calories": 450,
    "protein": 35,
    "time": "20分钟"
  },
  "dinner": {
    "name": "清蒸鲈鱼配时蔬",
    "calories": 380,
    "protein": 38,
    "time": "25分钟"
  }
}
```

---

## 任务 4: 计算采购

### 输入

```json
{
  "recipes": ["breakfast", "lunch", "dinner"]
}
```

### Agent 操作

```
1. 提取食材
2. 累加用量
3. 分类整理
```

### 输出

```json
{
  "shopping_list": [
    {"name": "鸡蛋", "amount": "10个", "category": "🥚 蛋奶"},
    {"name": "鸡胸肉", "amount": "500g", "category": "🥩 肉类"},
    {"name": "牛油果", "amount": "3个", "category": "🥬 蔬果"}
  ]
}
```

## 用户可验证点

| 环节 | 验证方式 |
|------|---------|
| 偏好输入 | 选择标签，立即反馈 |
| 分析过程 | 显示加载动画 |
| 结果展示 | 查看菜谱和数据 |
| 采购清单 | 可勾选、可导出 |
| 重新规划 | 重置并重新生成 |

---

## 失败状态处理

| 场景 | 处理方式 |
|------|---------|
| 未选偏好 | 提示「请至少选择一个偏好」 |
| 网络错误 | 显示错误信息，可重试 |
| 数据加载失败 | 显示默认数据，标注来源 |

## 演示脚本

```

3. 点击「开始规划」

```

# 1.9.0 预算协调版：Shell 真实模型联调记录

2026-10-10 晚。此页记录 **1.9.0 在 OctoSense 手机壳（`octosense-home`，mobile-only）中用真实 MiniMax-M3 完成“省钱+少辣”整周换餐**的实测结果。隔离环境与模型密钥配置在 `.local-state/shell-env/`（gitignore，不进仓库）。

## 环境

- 宿主：`octosense-home` release 构建（OctoSense `4a541777`），Linux，可见窗口 + 远程桥。
- 内核：锁定版 octos（`target/octos-kernel` release）。
- 模型：`minimax-cn` / MiniMax-M3，`https://api.minimax.cn/v1`。
- 应用数据：预置 `profile.json`（日预算 ¥32），本地测试目录经 `hub publish`（临时锚点）。

## 通过的流程（同一 bundle、同一次运行）

1. 周页生成七天草案：待确认 21 餐、缺口 1、重复 4、含 1 份副餐；预算账目列出逐日已计划/日预算。
2. 输入“这周想省点钱，少辣”，点“请 Agent 提案”。
3. MiniMax-M3 返回围栏 JSON：5 个日期各换 1 餐（全部午餐），理由含“不含辣字样、避免重复”。
4. 应用剥围栏、映射“日期+餐次”文本、校验编号与边界后展示：**Agent 提议 5 处替换，预计节省 ¥3.00**（节省额由应用按真实菜价算出，不信模型口算）。
5. 点“应用建议到草案”：状态显示调整了 5 餐，**计划文件数量不变**（草案未落盘）。
6. 点“确认整周草案”：已确认并读回核验 21 餐。
7. 读回 `plans-*.json`：2026-10-11 午餐已是 Agent 所选“牛肉丸面 ¥10.00”，总餐数 21。

原始模型回复见 [agent-week-190-reply-20261010.txt](agent-week-190-reply-20261010.txt)，解析阶段记录见 [agent-week-190-notes-20261010.txt](agent-week-190-notes-20261010.txt)。

# 1.5.0：首次使用与餐饮预算

日期：2026-10-04。运行环境：Linux 原生 Makepad `card-host`，OctoScript-App-Design-Flow `tools/octo run bundle`。本轮没有运行 OctoSense Shell 模型请求；真实 MiniMax 证据仍属于 1.2.2。

首次打开空数据目录，看到[新手引导](onboarding-150-20261004/00-first-run-setup.png)。当前可选数据是广州软件学院食堂的 1,497 条快照；引导明确说明其他食堂文件导入和自动采集未接入。输入月生活费 ¥1,500、非餐饮固定开销 ¥540、缓冲金 ¥0，页面显示每月餐饮 ¥960、日均 ¥32，并给出早餐/午餐/晚餐起始分配。点击开始后，`profile.json` 被写入并读回，进入[今日餐品首页](onboarding-150-20261004/01-home-recommendation.png)。已有计划的老用户继续先看今天安排。

此次进一步排除加料、配菜、纯主食、明显小份及无蛋肉等主菜线索的午晚餐条目。规则只根据菜名和类别判断；菜单没有份量、营养或过敏原，因此不宣称能保证吃饱或均衡。预算较低时引导明确提示人工核对。

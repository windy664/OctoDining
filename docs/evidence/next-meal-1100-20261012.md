1.10.0 界面变化（相对 1.9.0）：

- 首页下一餐卡新增**推荐来源行**：默认「本地规则引擎 · 菜单快照」；本次会话内系统 Agent 调用成功后变为「系统 Agent 已联调」，失败后变为「系统 Agent 暂不可用」。推荐来自哪里一眼可见。
- 候选卡新增「详情 ›」：展开固定面板，列出分类与本餐上限、到店时段核验、近七天重复次数、本机口味记录、菜单快照来源与更新日期；再点「收起 ↑」收回，切换语言后面板内容跟随刷新。
- 周餐表新增**本周预算进度卡**：八段进度条 + 「本周预算 ¥X · 已计划 ¥Y · Z%」，超支时提示改餐；确认、取消、打卡后自动更新。
- 首页主体改为可滚动视图：内容超出窗口（例如「需要留意」预警卡出现）时，底部「调整预算与时间 / 重新核算生活费 / 设置」操作行不再被裁掉；无预警时首屏完整显示主操作。
- 首页与候选页密度微调（标题、卡片内距），主 CTA 保持在首屏。

本版 card-host 回归（2026-10-12 凌晨，全部通过）：

- `test-basic-app.py` 17 项：首次核算、餐次上限、非法输入拒绝、Agent 不可用降级、确认/读回、替换不重复计数、打卡与撤销、日期隔离、损坏记录恢复等；

- `test-week-draft.py` 2 项：七天草案不写已确认计划、整周确认读回且不超每日预算；

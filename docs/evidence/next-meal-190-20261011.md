1.9.0 界面变化（相对 1.7.0 截图）：

- 首页下一餐卡新增「本餐 / 今日可用」预算指标条；
- 需求输入框下新增快捷 chips（少辣 / 快一点 / 吃好点 / 别重复），点按即填入需求并请 Agent 比较；
- 候选卡新增「证据」行：价格对本餐上限、到店时段是否营业、菜名辣味词、近七天是否吃过；
- 周餐表餐次改为右侧状态 pill：绿底「已吃」、灰底「待吃」；
- 周视图顶部新增本周预算结算行（本周可用 / 已计划 / 按已吃还剩）；
- 首页新增本地规则的主动「需要留意」卡：所选日期超支、同一菜品本周排满 3 次时主动提醒，无需模型在线；
- 全部 1,209 张菜单配图以 96px JPEG 打进 bundle（`bundle/menu/`，约 4.8 MB），经 `{{assets}}` 本地回环加载，断网也可渲染；CDN 地址仅作打包失败时的回退。

本版 card-host 回归：`test-week-draft.py`、`test-week-agent.py`、`test-taste.py`、`test-custom-menu.py` 通过；`test-basic-app.py` 仅在 06:00–20:00 的食堂时间窗口内有效（窗口外首页按语义切换到次日早餐，日期断言按设计失败）。1.9.0 Shell 真实模型闭环尚待补验，不能引用旧版本记录代替。

截图脚本在商品图加载后采样，图片取自内置 `menu.csv` 关联 URL；图片仅供参考。旧版画面见 [1.7.0 记录](next-meal-170-20261005.md)。

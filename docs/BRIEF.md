# 任务说明：校园美食规划助手

## 一句话描述

> 让 AI 帮学生规划一周校园美食，自动生成营养均衡的菜谱和采购清单

---

## 用户问题

### 痛点分析

| 问题 | 现状 | 影响 |
|------|------|------|
| 不知道吃什么 | 每天纠结，浪费时间 | 体验差 |
| 营养不均衡 | 随意搭配，不健康 | 身体影响 |
| 采购靠手写 | 容易遗漏，重复买 | 效率低 |
| 预算难控制 | 花钱没计划 | 经济压力 |

### 目标用户

- 🎓 大学生（主要）
- 👨‍🍳 校园周边商家
- 🏠 宿舍/租房群体

---

## 任务定义

### 输入

```
用户选择偏好标签（可多选）：
- 🥬 清淡
- 🌶️ 微辣
- 🍖 高蛋白
- 🥗 健康
- ⚡ 快手菜
- 🎯 低卡
- 🍜 面食
- 🥘 炖菜
```

### Agent 任务

| 步骤 | 任务 | 输入 | 输出 |
|------|------|------|------|
| 1 | 分析偏好 | 用户选择的标签 | 偏好画像 |
| 2 | 匹配营养 | 偏好画像 + 营养库 | 营养需求 |
| 3 | 生成菜谱 | 营养需求 + 菜谱库 | 早/午/晚餐 |
| 4 | 计算采购 | 菜谱 + 用量模板 | 采购清单 |

### 输出

```
1. 营养统计
   - 总热量 (kcal)
   - 蛋白质 (g)
   - 菜品数

2. 今日菜谱
   - 早餐: 名称 + 热量
   - 午餐: 名称 + 热量
   - 晚餐: 名称 + 热量

3. 采购清单
   - 食材名称
   - 用量
   - 分类
   - 可勾选
```

## 用户操作流程

```
1. 打开应用
   ↓
2. 选择偏好标签（如：健康、快手菜）
   ↓
3. 点击「开始规划」
   ↓
4. Agent 自动工作（显示进度）
   ↓
5. 查看结果
   ├─ 营养统计
   ├─ 今日菜谱
   └─ 采购清单
   ↓
6. 勾选已购买食材
   ↓
7. 需要时点击「重新规划」
```

# 菜单快照来源与使用边界

本项目保留原有的广州软件学院食堂菜单数据。仓库中的 `menu.csv` 有 2,078 行、42 个店铺 ID；`products_clean.json` 有 1,497 条商品记录。1.6.1 构建时按商品名、店铺、价格、分类、营业时间及原始行顺序将两者对应，为 1,209 条有非默认商品图的记录嵌入图片 URL。商品内容和 Agent 请求仍只基于本地快照，不查询实时菜单；首页可按商品从外部图片域名加载配图。

`menu.csv` 的图片 URL 指向 `img.pospal.cn`，但这只能确认文件中记录的图片地址，不能据此断定整个数据集的采集接口或授权来源。CSV 的“创建时间”字段跨度为 2021-10-11 至 2026-09-23，属于记录字段，**不是**已核实的抓取或导出日期。精确采集时间、原始出处和公开再分发许可尚缺凭据；因此代码的 Apache-2.0 许可不应被理解为第三方菜单数据的许可。

原始 CSV 还包含店铺电话、地址和图片 URL。当前应用包不嵌入 CSV 中的电话，应用也不发送这些电话给模型；公开源码仓库仍保留原始数据文件。应用包嵌入的是菜单图片链接而非图片文件，运行时仅向 `img.pospal.cn` 加载对应图片；第三方图片可能失效，且不保证与菜品名称完全一致或为实拍。使用者应独立核对价格、营业时间、库存和食品信息，应用不提供下单或支付。

构建入口为 `python3 scripts/build-octos-bundle.py`，输入是 `products_clean.json` 和 `menu.csv`，输出是 `bundle/main.splash`。若取得更明确的来源和授权，应在此记录证据链接、采集日期与允许再分发的范围，再更新对外说明。
